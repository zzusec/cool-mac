# 清凉风扇

当前版本 **1.1.24（构建 27）**；可在「设置」查看版本，在「检查更新…」窗口查看版本与构建号。

macOS 菜单栏风扇工具（Apple Silicon、macOS 14+、arm64）。常驻屏幕右上角，不占 Dock。

本仓库只用于分发**安装包**与**更新清单**，不包含源代码，也不包含任何本机配置、诊断数据或签名私钥。

## 安装

在 [Releases](https://github.com/zzusec/cool-mac/releases) 下载最新 DMG，打开后双击其中的安装包，按 macOS Installer 的管理员授权完成安装。安装会同时放入应用与一个 root-owned 后台组件。

DMG 只提供一个安装包，不需要拖拽应用，也不需要单独安装后台。安装前退出旧版，安装完成后打开「清凉风扇」，按「设置 → 安全自检…」启用控制。

## 功能

- **系统自动**：完全交由 macOS 控制。
- **凉爽自动**：以系统控制为基础，温度升高时更早加速散热。
- **增强转速**：用滑块按 10% 一档，在系统当前转速之上增加转速，最高不超过额定上限的 80%。只加不减，绝不低于系统要求的转速。
- **强力散热**：限时两分钟。
- **自动升级**：默认开启，可在「设置 → 自动更新」关闭；启动后及每 6 小时检查，发现兼容新版会自动下载、验签并安装。也可通过「设置 → 检查更新…」手动更新。

所有由本程序下发的目标都夹在额定上限的 80% 以内；传感器异常、写入或回读不符、实测转速不响应、温度过高、热压力严重、检测到其他风扇控制程序或界面失联时，一律交还系统自动控制。此时系统可以使用满转速。

显示的是芯片传感器温度，不是机身表面温度。更积极散热会增加风扇噪声和电池消耗，也无法保证持续高负载时机身不热。

## 更新校验

更新清单使用 Ed25519 签名，安装包按 SHA-256 与精确长度校验。签名、摘要或版本任一项不符都不会安装。安装前先确认风扇已安全交还系统自动，未确认就中止；已安装后台会重新验签、拒绝降级并校验安装包副本后安装。首次安装需要管理员授权，后续更新没有新的管理员授权弹窗。

安装完成后，客户端会核对磁盘上的版本与构建号及后台完整安装成功记录，确认后才自动重启应用；更新失败会显示提示，不会冒充成功。

## 说明

- 本地构建，使用 ad-hoc 签名与 Hardened Runtime，**未经过 Apple 公证**，也不是 Apple 官方软件。
- 当前硬件支持以本机安全自检为准；首次启用风扇控制前会先做一次短时升速与恢复验证。
- 其他风扇控制软件（如 Macs Fan Control、Stats）不应同时使用；检测到冲突时本程序会停止接管。
